## 2. 핵심 기능 요약 (중학생 수준 설명)

### 📂 사업비 자료실 (비밀 도서관)
*   **개념:** 특정 기수(예: 2기) 학생들만 들어갈 수 있는 보안 도서관.
*   **작동:** 관리자가 '그룹' 명단에 유저를 추가하면, 유저는 본인 기수에 맞는 게시물을 볼 수 있음.
*   **보안:** Supabase RLS 기술을 사용하여 권한이 없는 유저는 데이터에 접근조차 불가능.

### 🤝 1:1 컨설팅 지원 (전문가 과외)
*   **개념:** 전문가의 비어 있는 시간을 확인하고 예약하는 시스템.
*   **과정:** 유저 신청 → 관리자/전문가 검토 → **[승인]** → 예약 확정.
*   **특징:** 관리자 페이지에서 전문가 목록과 상담 가능 시간(슬롯)을 통합 관리.

### 🏃‍♂️ Founder's Club (선착순 동아리)
*   **개념:** 소수 정예(예: 6명)가 모이는 선착순 게시판.
*   **자동화:** 정원이 차면 시스템이 자동으로 '마감' 처리 (DB 트리거 작동).
*   **관리:** 관리자는 모임의 주제와 최대 인원을 설정하고 신청 현황을 모니터링.
