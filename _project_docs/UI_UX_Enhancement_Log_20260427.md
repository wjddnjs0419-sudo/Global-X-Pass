# UI/UX Design System Enhancement Log (2026.04.27)

## 📋 작업 개요
프로젝트의 공식 디자인 가이드라인인 **"Orbital System"**과 **"Glassmorphism"** 철학을 메인 페이지 전반에 이식하고, 파편화되어 있던 UI 컴포넌트들을 하나의 일관된 시스템으로 통합함.

## 🛠️ 주요 수정 사항

### 1. 전역 UI 컴포넌트 고도화 (`src/app/components/ui/`)
- **Badge (배지):**
  - 모든 카테고리 라벨을 세련된 **Pill(알약) 형태**로 통일.
  - 좌측에 시각적 위계를 높여주는 **인디케이터 점(Dot)** 추가.
  - 브랜드 컬러별(Blue, Green, Yellow, Red) 투명도 기반 글래스 스타일 적용 (15% 배경, 40% 테두리).
  - 다크모드 대응: `secondary`(FAQ), `outline` 변형의 테두리 농도 및 텍스트 밝기를 상향 조정하여 시인성 확보.
- **Button (버튼):**
  - 모든 주요 CTA 버튼을 **Pill 형태**로 변경.
  - 굵은 폰트(`font-bold`)와 부드러운 애니메이션(`duration-300`) 적용.
  - `outline`, `ghost` 변형에서 배경색을 투명(`bg-transparent`)하게 처리하여 라이트 모드에서 검게 보이던 버그 해결.

### 2. 섹션별 디자인 시스템 통합
- **NoticeSection (공지사항):**
  - 키컬러: **Red**.
  - 배지 및 전체보기 버튼에 레드 테마 일괄 적용.
- **EventSection (행사 소식):**
  - 키컬러: **Green**.
  - 대표 행사(Featured Card) 내부의 날짜/장소 태그를 글래스 스타일 배지로 교체.
  - 리스트 항목의 이벤트 배지를 테마 컬러 순환 방식으로 고도화.
- **NewsletterSection (뉴스레터):**
  - 키컬러: **Yellow (#FBBC05)**.
  - 공지사항(Red)과의 컬러 충돌을 피하기 위해 옐로우 테마로 전면 교체.
  - 구독 버튼에 브랜드 그라데이션 적용 및 전체보기 버튼 디자인 시스템 통합.
- **CommunitySection (최신 게시물):**
  - 필터 탭 활성화 컬러: **Purple (#A855F7)**.
  - 뉴스레터(Yellow)와의 구분을 위해 퍼플 컬러 도입 및 세련된 그림자 효과 추가.
  - 사라졌던 FAQ 배지를 복구하고 고도화된 `secondary` 스타일 적용.

### 3. 테마 및 안정성 (Dark/Light Mode)
- **배경색 고정 버그 해결:** `bg-background` 대신 `bg-transparent`를 명시적으로 사용하여 라이트 모드에서 UI 요소가 어둡게 렌더링되던 문제 근본적 해결.
- **가독성 최적화:** 다크모드 시 배지 테두리 불투명도를 `0.35`로 상향하고 텍스트 밝기를 조정하여 '인사이트' 배지와 동일한 수준의 가시성 확보.

## 🏁 최종 결과
- 메인 페이지의 모든 섹션이 개별 커스텀 스타일이 아닌 **공통 UI 컴포넌트(`Badge`, `Button`)**를 참조하도록 리팩토링됨.
- 다크/라이트 테마 전환 시 레이아웃 무너짐이나 색상 반전 오류 없이 완벽하게 대응함.
- `dist` 폴더 최신화 완료.
